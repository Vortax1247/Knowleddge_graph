# Public / private repository boundary

## Included

- architecture diagrams;
- governance principles;
- sanitized example contracts;
- aggregate, verified evaluation results;
- honest current-state documentation.

## Excluded

- raw conversations and user prompts;
- identity and personal memory records;
- preference datasets and holdout contents;
- runtime logs and audit chains;
- absolute local paths;
- model weights, adapters and licensed datasets;
- service credentials, tokens and environment files;
- production configuration;
- the private Git history.

## Publication method

Create a new empty public repository from this directory. Do not convert the private development repository to public and do not import its history.
